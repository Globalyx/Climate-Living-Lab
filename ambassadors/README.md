# 👥 Climate Ambassadors Network

> “Leadership in climate action is not about control — it’s about connection.”  
> — *Carolina Hedman*

The **Climate Ambassadors Network** connects leaders across Europe and Latin America who guide, document, and amplify the transformation *From Seed to Shift*.

Each ambassador facilitates local Living Labs, engages municipalities, schools, and communities, and contributes to shared learning across regions.

## 📘 How to Add or Edit Your Profile

1. Go to `/ambassadors/profiles/`
2. Duplicate the file `TEMPLATE.md`
3. Rename it with your full name (example: `Evi-Makri.md`)
4. Fill in your information and upload a photo
5. Upload your CV (PDF or Word) to `/ambassadors/cv/`
6. Update this table if necessary
