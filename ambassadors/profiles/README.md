# 👥 Ambassador Profiles

This folder contains the official profiles of all **Climate Living Labs Ambassadors**.

Each profile should:
- Follow the `TEMPLATE.md` format.
- Include a profile photo (PNG or JPG).
- Include links to social media and the official CV (PDF).
- Be named using the ambassador’s full name, e.g.:
  `Carolina-Hedman.md`
